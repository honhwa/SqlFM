# SQL 格式化工具功能详细清单

> 综合 Poor Man's T-SQL Formatter、Redgate SQL Prompt、dbForge SQL Complete 三款主流工具的功能，
> 剔除冷门/边缘特性，保留实际开发中高频使用的核心功能。

---

## 一、核心格式化操作

| 功能 | 说明 |
|------|------|
| 格式化选中代码 | 对编辑器中选中的 SQL 片段执行格式化 |
| 格式化全部代码 | 对当前文档全部 SQL 执行格式化 |
| 保存时自动格式化 | 文件保存时自动触发格式化（可开关） |
| 格式化选中大小写转换 | 对选中代码单独执行关键字大写/小写转换 |
| 快捷键触发 | Ctrl+K,F（格式化选中）/ Ctrl+K,D（格式化全部）等标准快捷键 |
| 右键菜单集成 | 在编辑器右键菜单中提供格式化入口 |

---

## 二、缩进与空白控制

| 功能 | 说明 |
|------|------|
| 缩进类型 | 空格（Spaces）或制表符（Tabs） |
| 缩进宽度 | 空格数量（默认 4） |
| 最大行宽 | 超过指定字符数时自动换行（默认 120） |
| 删除行尾空格 | 格式化后移除每行末尾的多余空格 |
| 合并连续空格 | 将多个连续空格压缩为单个 |
| 移除多余空行 | 超过设定数量的连续空行自动裁剪 |
| 语句间空行数 | 顶级语句之间的空行数量（默认 1） |
| 子句间空行数 | SELECT/FROM/WHERE 等子句之间的空行数量（默认 0） |
| GO 前后空行 | GO 批处理分隔符前后的空行数量 |

---

## 三、大小写控制

| 功能 | 选项 | 说明 |
|------|------|------|
| 关键字大小写 | 大写 / 小写 / 首字母大写 | SELECT / select / Select |
| 内置函数大小写 | 大写 / 小写 / 首字母大写 | GETDATE() / getdate() |
| 数据类型大小写 | 大写 / 小写 / 首字母大写 | VARCHAR / varchar |
| 对象名称大小写 | 保持 / 大写 / 小写 | 表名、列名等标识符 |
| 变量参数大小写 | 保持 / 大写 / 小写 | @变量名、存储过程参数 |

---

## 四、SELECT 语句格式化

| 功能 | 说明 |
|------|------|
| 逗号位置 | 行末后置（`col1,`）或行首前置（`, col1`） |
| AS 关键字处理 | 保持 / 移除 AS / 对齐 AS 列 |
| 列别名纵向对齐 | 多列别名在 AS 后纵向对齐 |
| 长函数调用换行 | 超过行宽时对函数参数换行展开 |
| 列注释对齐 | 行内注释（--）纵向对齐 |
| SELECT * 展开 | 将 `SELECT *` 展开为实际列名（需数据库元数据） |

---

## 五、FROM / JOIN 格式化

| 功能 | 说明 |
|------|------|
| JOIN 关键字另起新行 | 每个 JOIN 单独一行 |
| JOIN 表缩进 | JOIN 的表相对 FROM 额外缩进 |
| ON 条件缩进层级 | ON 后条件相对 JOIN 的缩进层数 |
| 逻辑运算符位置 | AND/OR 前置（行首）或后置（行末） |
| 隐式 JOIN 转显式 | 逗号连接 → INNER JOIN 语法 |

---

## 六、WHERE 子句格式化

| 功能 | 说明 |
|------|------|
| 条件统一缩进 | WHERE 下所有条件统一缩进（含第一个） |
| IN 列表换行 | IN (...) 列表过长时自动换行 |
| 比较运算符对齐 | 多行条件中的 = / <> / > 等纵向对齐 |
| 嵌套括号缩进 | 括号内的条件额外缩进一层 |

---

## 七、GROUP BY / HAVING / ORDER BY

| 功能 | 说明 |
|------|------|
| GROUP BY 每列独占一行 | 分组列逐行展开 |
| HAVING 复用 WHERE 风格 | HAVING 条件采用与 WHERE 相同的缩进/换行规则 |
| ORDER BY 排序方向对齐 | ASC/DESC 右对齐 |
| 窗口函数缩进 | OVER (PARTITION BY ...) 子句缩进展开 |

---

## 八、INSERT / UPDATE / DELETE / MERGE

| 功能 | 说明 |
|------|------|
| INSERT 列列表换行 | 列过多时自动换行展开 |
| VALUES 多行对齐 | 多行 VALUES 数据纵向对齐 |
| UPDATE SET 等号对齐 | SET 子句中的赋值等号纵向对齐 |
| MERGE 分支缩进 | WHEN MATCHED / WHEN NOT MATCHED 额外缩进 |
| OUTPUT 子句换行 | OUTPUT 子句展开为独立行 |

---

## 九、CTE（公用表表达式）

| 功能 | 说明 |
|------|------|
| 简单 CTE 单行压缩 | 单个简单 CTE 压缩为一行 |
| CTE 逗号换行 | 多 CTE 时分隔逗号另起新行 |
| CTE 查询体缩进 | CTE 内部查询相对 WITH 的缩进层数 |
| CTE 间空行分隔 | 多个 CTE 之间用空行隔开 |
| 递归 CTE UNION 缩进 | UNION ALL 相对 CTE 查询体的缩进方式 |

---

## 十、CASE 表达式

| 功能 | 说明 |
|------|------|
| 每个 WHEN 独占一行 | WHEN 分支逐行展开 |
| WHEN 条件缩进 | WHEN 相对 CASE 的缩进层数 |
| THEN 值对齐 | THEN 后的值与其他分支纵向对齐 |
| ELSE 另起新行 | ELSE 分支单独一行 |
| END 与 CASE 对齐 | END 与 CASE 关键字在同一列 |
| 简单 CASE 单行压缩 | 只有一个 WHEN 时压缩为一行 |

## 十一、流程控制

| 功能 | 说明 |
|------|------|
| IF 与 BEGIN 同行 | BEGIN 紧跟 IF 同一行 |
| END 对齐 IF 缩进 | END 与对应 IF/BEGIN 的缩进对齐 |
| IF/ELSE 间空行 | IF 块与 ELSE 块之间插入空行 |
| TRY/CATCH 块缩进 | TRY/CATCH 内部语句缩进 |
| DECLARE 每行一个 | 多个变量声明拆分为每行一个 |
| EXEC 参数换行 | EXEC 参数过多时自动换行 |

| 约束定义对齐 | PRIMARY KEY / DEFAULT 等约束纵向对齐 |
| 存储过程参数换行 | 每个参数独占一行 |
| 函数返回类型格式化 | RETURNS 子句换行展开 |
| 触发器表引用缩进 | INSERTED/DELETED 表引用缩进对齐 |

## 十四、括号、分号与引号

| 功能 | 说明 |

## 十五、T-SQL 专属规则

## 二十、CLI 命令行与 CI/CD

| 功能 | 说明 |
|------|------|
| 单文件格式化 | `ssmsfmt -f file.sql -o output.sql` |
| 目录批量格式化 | `ssmsfmt -d ./scripts --recursive` |
| 检查模式（--check） | 只检测是否需要格式化，不修改文件，返回退出码 |
| 自定义样式文件 | `--style mystyle.sqlstyle` 指定格式化规则 |
| 编码指定 | `--encoding utf-8` 指定文件读写编码 |
| 递归子目录 | `--recursive` 递归处理子目录 |
| 退出码 | 0=无修改 / 1=有修改 / 2=部分失败 / 3=参数错误 / 4=致命错误 |
| CI/CD 集成 | 可嵌入 GitHub Actions / Azure DevOps 流水线 |

## 已剔除的冷门功能

以下功能在三款工具中属于低频/边缘特性，不在本清单中：

- HTML 彩色输出（Poor Man's 独有，实际开发几乎不用）
- Notepad++ / WinMerge 插件（非 SSMS 场景）
- 代码补全 / IntelliSense（属于编码辅助，非格式化范畴）
- T-SQL 调试器（dbForge 独有，属于调试范畴）
- 查询历史记录（生产力扩展，非格式化）
- 结果网格聚合计算（数据查看功能）
- 代码分析 / 静态检查（代码质量工具，非格式化）
- 无效对象查找（数据库管理功能）
- Tab 着色（UI 辅助功能）
- AI 自然语言转 SQL（AI 编码辅助，非格式化）
